## 📖 About ClickRaids

**_ClickRaids_** is a high-concurrency, real-time web application, inspired by the viral [OneMillionCheckBoxes](https://onemillioncheckboxes.com) game, created by [eieio games](https://eieio.games). While the original game was a fun experiment, **_ClickRaids_** aims to push the boundaries by exploring how well a single server can be optimized to handle millions of users simultaneously. The goal is to serve as many users as possible (High Performance), process requests as quickly as possible (Low Latency), and avoid downtime for as long as possible (High Availability) to see just how far an efficient application can go without relying on infrastructure scaling.
